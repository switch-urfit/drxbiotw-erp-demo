# DRX 生產排程協調平台 — 排程升級功能展示（Angular Demo）

給使用者看的互動示範系統：展示四個即將升級的自動化功能。機台（13 台）與作業員（8 位）
資料為 2026-06-17 正式系統（production.drxbio.com）快照；純前端模擬，**不連接、不影響正式資料**。

## 功能頁面

| 頁面 | 展示內容 |
|------|----------|
| 儀表板 | 全廠今日產能總覽、缺勤／停機／未排班警示、13 台機台狀態 |
| 每日排班 × 產能 | 加派／調離作業員（技能過濾＋不可同時排兩台）、缺勤登記 → 產能與交期即時重算 |
| 插單衝擊預覽 | 按「機台產能 × 當天人力」精準試算漣漪延遲，新舊估法對照，確認後寫入佇列 |
| 停機自動順延 | 停機紀錄 → 自動換算順延天數、整批連動順延（甘特圖前後對照） |
| QMS 文件產生 | 出貨工單一鍵產出 製令單／批次紀錄／出貨單 PDF ＋ 鼎新 ERP CSV（流程圖 step 11） |
| 稽核紀錄 | 全站操作即時寫入（ISO 13485：誰、改什麼、何時、為什麼） |

## 啟動（開發模式）

```bash
npm install        # 第一次
npm start          # http://localhost:4200
```

## 打包（給使用者看的靜態版）

```bash
npm run build      # 產出 dist/scheduler-demo/browser/
```

打包後用任何靜態伺服器供檔即可，例如：

```bash
npx http-server dist/scheduler-demo/browser -p 8081
```

## 排程邏輯（與《排程邏輯說明》一致）

- 當天該機產能（片/分）＝ 每人每分鐘產能 × 當天實際上線人數
- 一天工作 480 分鐘（09:00–18:00 扣午休 60 分）；工單需時以天無條件進位
- 沒有排班 ＝ 那台機不開工；同一人同時段不能排兩台；只能排會操作該機型的人
- 插單：後面的單排隊號碼整批後移；衝擊預覽為試算、確認後才寫入
- 停機：時數 ÷ 8 工作小時 ＝ 順延天數，該機所有未完成單整批順延

## 技術

Angular 20（standalone components + signals）、無其他相依套件、紫色主題＋深色模式（跟隨系統）。
